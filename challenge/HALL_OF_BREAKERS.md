# Hall of Breakers

No verified authority break has been recorded in this repository snapshot.

A valid entry requires a reproducible proof that satisfies the challenge rules,
including identical relevant ground truth for influence claims. Agent compromise
alone is expected behavior and does not qualify.

When a valid break is confirmed, record:

- researcher / team name (or anonymous attribution);
- affected Release Sentinel version and commit;
- broken invariant;
- minimal reproducer digest;
- disclosure date;
- remediation commit; and
- permanent regression-test identifier.
